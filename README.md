# Audoiboo-Tracker

Проєкт Audoiboo-Tracker — простий інструмент для відстеження прослуховування аудіокниг. Він покликаний допомогти користувачам вести бібліотеку аудіокниг, зберігати поточний прогрес прослуховування та помічати завершені чи активні записи.

> Примітка: README написано українською. Вміст та інструкції є загальними; змініть розділ "Технології" та інструкції з інсталяції під поточну реалізацію проєкту.

## Можливості

- Додавання/редагування/видалення записів аудіокниг
- Відстеження прогресу прослуховування (текуща позиція / відсоток)
- Позначення завершених книг
- Пошук та фільтрація бібліотеки
- (Опціонально) Синхронізація з хмарою або експортування/імпорт бібліотеки

## Швидкий старт

1. Склонуйте репозиторій:

```bash
git clone https://github.com/thirteenth13/Audoiboo-Tracker.git
cd Audoiboo-Tracker
```

2. Встановіть залежності (приклади — відкоригуйте під стек проєкту):

- Для Node.js/JavaScript/TypeScript проєкту:

```bash
npm install
# або
yarn install
```

- Для Python проєкту (якщо є requirements.txt):

```bash
python -m venv .venv
source .venv/bin/activate  # Linux / macOS
.\.venv\Scripts\activate   # Windows
pip install -r requirements.txt
```

3. Збережіть конфігурацію (якщо потрібно). Налаштуйте .env або інші файли конфігурації згідно з документацією проєкту.

4. Запуск додатку (приклади):

```bash
npm run dev     # локальна розробка
npm start       # продакшн (якщо налаштовано)
# або для Python:
python main.py
```
