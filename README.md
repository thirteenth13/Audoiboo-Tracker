# Audoiboo Tracker

Android-застосунок для відстеження книжкових серій на Audioboo.

## Мета

- додавати кілька серій Audioboo за URL;
- отримувати список книг зі сторінки серії;
- бачити нові книги;
- позначати книги як непрочитані / читаю / прочитані;
- зберігати посилання на сторінку книги;
- надалі витягувати посилання на архів для завантаження;
- автоматично перевіряти появу нових книг.

## Поточний стан

Перша MVP-версія вже містить Android-проєкт на Kotlin + Jetpack Compose і WebView-парсер. Як тестова серія за замовчуванням використовується «Другая сторона».

Audioboo може повертати HTTP 403 для звичайних автоматичних HTTP-запитів, тому парсинг планується виконувати через Android WebView, який завантажує сайт як браузер і читає DOM після завантаження сторінки.

## Технології

- Kotlin
- Jetpack Compose
- Android WebView
- Android API 23+
- compileSdk / targetSdk 37
- Android Gradle Plugin 9.3
- JDK 17
- GitHub Actions

## Збірка

GitHub Actions автоматично запускає debug-збірку після push у `main`.

Локально:

```bash
gradle :app:assembleDebug
```

APK після CI доступний в GitHub Actions як artifact `AudoibooTracker-debug`.

## Наступні кроки

1. Уточнити DOM-селектори на реальних сторінках Audioboo.
2. Додати локальну базу серій і книг.
3. Додати статуси NEW / UNREAD / READING / READ.
4. Парсити сторінку конкретної книги та знаходити кнопку/URL архіву.
5. Додати DownloadManager.
6. Додати фонову перевірку та Android-сповіщення.
7. Додати експорт/імпорт стану бібліотеки.
